¿Qué es PHP?

PHP (Hypertext Preprocessor) es un lenguaje de programación de código abierto diseñado originalmente en 1994 para el desarrollo web del lado del servidor. Esto significa que el código se ejecuta en el servidor web antes de enviar la página resultante (en HTML) al navegador del usuario. Es uno de los pilares históricos de la web dinámica y se caracteriza por su facilidad de integración con bases de datos como MySQL.

¿Cómo funciona en una página web?

Cuando visitas una página dinámica, el navegador envía una petición al servidor. Si la página necesita PHP, el servidor ejecuta ese código y puede usarlo para preparar la respuesta, por ejemplo, consultando una base de datos.

  1. El navegador solicita una página.
  2. El servidor ejecuta el código PHP y genera el contenido solicitado.
  3. El servidor envía el resultado, normalmente HTML, y el navegador lo muestra.

Por ejemplo, este sencillo script genera el texto «Hola, mundo» en el servidor:

<?php echo "Hola, mundo"; ?>

El navegador recibe el resultado, no el código PHP que lo produjo. Puedes consultar el ejemplo de la documentación oficial de PHP.

Usos

A pesar de ser un lenguaje veterano, PHP sigue moviendo una parte gigantesca de Internet:

  • Sistemas de Gestión de Contenidos (CMS): Plataformas masivas como WordPress (que impulsa más de un 40 % de las webs del mundo), Drupal y Joomla están escritas en PHP.
  • Comercio electrónico: Gran parte de las tiendas online creadas en Magento o WooCommerce dependen de este lenguaje.
  • Frameworks modernos: Frameworks robustos como Laravel y Symfony permiten desarrollar aplicaciones web empresariales, seguras y altamente escalables utilizando PHP moderno.
