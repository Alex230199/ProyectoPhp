Comprobar la protección de TwinTeach

TwinTeach utiliza Angular en el frontend y Laravel en el backend. Laravel se ejecuta sobre PHP, por lo que la versión instalada en el servidor del backend debe comprobarse y actualizarse.

Comprobar la versión de PHP

  1. Accede por SSH al servidor donde se ejecuta Laravel.
  2. Ejecuta este comando para ver la versión de PHP disponible en la terminal:
php -v

Comprueba también la versión que utiliza el servidor web o PHP-FPM, ya que puede ser distinta de la versión de la terminal. Según el texto aportado, las versiones corregidas indicadas son 8.5.12, 8.4.27, 8.3.36 y 8.2.35. Si el servidor utiliza una versión anterior, actualízala a una versión corregida y compatible con el proyecto.

Revisar las capas de red

Comprueba que los servidores o proxies inversos expuestos a Internet, como Nginx, Apache o Cloudflare, tengan activas las reglas de protección disponibles mientras se prepara la actualización de PHP. Estas medidas son temporales y no sustituyen la actualización.

Buscar indicios de explotación

La detección puede ser difícil porque un ataque podría ocurrir antes de que Laravel registre la petición. Revisa los siguientes indicios en los registros y sistemas de auditoría:

  • Registros de Nginx, Apache o PHP-FPM: busca peticiones anómalas o repetidas relacionadas con la subida de archivos, cabeceras Content-Type inusuales y errores repentinos de memoria (OOM).
  • Auditoría del sistema operativo: revisa las alertas de herramientas de integridad de archivos (FIM) y auditoría de procesos, como auditd en Linux.
  • Procesos del usuario de PHP: investiga si el usuario que ejecuta PHP, por ejemplo www-data, inició procesos de consola inesperados, abrió una shell o descargó archivos desconocidos.

La ausencia de estos indicios no demuestra por sí sola que el sistema no haya sido comprometido. Si aparecen señales sospechosas, conserva los registros y solicita una revisión de seguridad del servidor.
